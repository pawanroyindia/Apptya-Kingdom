# Apptya Kingdom

Apptya Kingdom is a mobile-first fantasy kingdom strategy game prototype built in Unity.

## Current prototype systems

- Runtime-generated kingdom scene and procedural blockout environment
- Resource gathering and passive production
- Keep and village-building upgrades with timers
- Guard training, scouting, enemy battles, and regional exploration
- Tutorial progression and claimable achievement rewards
- Local save snapshots with backup recovery and bounded offline progress
- Runtime HUD with safe-area handling and building selection

## Open the Unity project

1. Install **Unity 6000.0.46f1** (Unity 6) using Unity Hub.
2. Open the `UnityProject` folder as a Unity project.
3. In the Unity Editor, run **Apptya Kingdom > Setup Starter Scene** from the menu.
4. Use **Apptya Kingdom > Validate Project** to run the project's editor-side preflight checks.
5. Open the generated starter scene and use Play Mode to inspect the prototype.

The starter scene is generated by the editor setup tool and may not exist in the repository until setup has been run.

## Verification status

Source changes are committed to the `main` branch. **Unity Editor compilation, Play Mode gameplay, Android builds, and physical-device testing have not been verified here.** Static source review is not a substitute for those checks.

No APK is built or provided by this repository workflow. Android packaging should only be added after it is explicitly requested and the Unity project has been validated.

## Current limitations

This remains an early gameplay prototype. The environment uses procedural blockout visuals; original production-quality art, animations, deeper campaign content, multiplayer, and release-grade performance validation remain future work.
