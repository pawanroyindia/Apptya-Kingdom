# Scene setup

Open the UnityProject folder in Unity 6. After Unity finishes importing scripts, use:

**Apptya Kingdom → Setup Starter Scene**

The editor utility creates ApptyaKingdom.unity, adds the bootstrap component, and registers the scene in Build Settings. Then press Play and check the Console.

This creates only a procedural prototype blockout. It does not create final-quality character models, hand-authored environment assets, animations, or a verified Android APK.
