# Third-party runtime assets

- Royal Captain and guard: Quaternius RPG Character Pack models, sourced from the pinned CC0 asset snapshot in Hakhyun-Kim/constellation-defense (commit 8ad1c93e382e2a6a5755882c1b9b2922877fab6e). The UV-mapped GLBs retain the authored rigs and animation clips.
- Watchtower: Quaternius Medieval Village MegaKit gate-tower model, CC0 1.0 Universal.
- Keep and barracks: assembled in Blender from the MegaKit's authored wall and roof modules, including base-colour, normal, and roughness/ORM textures. Source textures are resized to 512px for mobile delivery. The original CC0 license is retained in `source_models/QUATERNIUS_CC0_1.0.txt`.
- Sound effects: Kenney RPG Audio / Impact Sounds CC0 1.0 samples mixed with the project's original transient layers. Source OGG files are retained in `source_sfx/`.
- Kingdom score: "Once Upon a Time (loop)" by TAD, CC0 1.0, from OpenGameArt. The source MP3 is retained in `source_music/`; the runtime stereo WAV is looped by the game.
- Generated fallback GLBs and source-only files are retained for development but excluded from the Android export preset.

Sources: https://quaternius.com/packs/rpgcharacters.html ; https://quaternius.com/packs/medievalvillagemegakit.html ; https://kenney.nl/assets/rpg-audio ; https://kenney.nl/assets/impact-sounds ; https://opengameart.org/content/once-upon-a-time-loop
