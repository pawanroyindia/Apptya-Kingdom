# Third-party runtime assets
- Character and gate-tower models: Quaternius RPG Character Pack and Medieval Village MegaKit, CC0 1.0 Universal. Keep and barracks are assembled from the pack's textured wall and roof modules. Source repository snapshot: Hakhyun-Kim/constellation-defense at commit 8ad1c93e382e2a6a5755882c1b9b2922877fab6e. The GLB models are used without geometry or texture edits.
- Sound samples: Kenney, RPG Audio / Impact Sounds selections, CC0 1.0 Universal. The source OGG files are retained in `source_sfx/`; each runtime WAV mixes one source sample with the project's original generated effect.
- Kingdom score: "Once Upon a Time (loop)" by TAD, CC0 1.0, from OpenGameArt; source MP3 is retained in `source_music/` and converted to the runtime WAV without trimming.
- Source: https://quaternius.com/packs/rpgcharacters.html ; https://quaternius.com/packs/medievalvillagemegakit.html ; https://kenney.nl/assets/rpg-audio ; https://kenney.nl/assets/impact-sounds ; https://opengameart.org/content/once-upon-a-time-loop
