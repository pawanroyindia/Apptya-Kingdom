# Apptya Kingdom generated assets and third-party provenance
- Royal Captain and guard runtime meshes are generated by `tools/asset_pipeline/generate_models.py`, with original layered armor details, UVs, PBR maps, weighted armatures and Idle/Walk/Attack clips. Pinned Quaternius CC0 characters are retained as comparison/reference assets under `source_models/`, not used as the runtime hero/guard.
- Watchtower: Quaternius Medieval Village MegaKit gate-tower model. Keep and barracks are assembled from the kit's textured wall/roof modules; source PBR textures are resized to 512px for mobile.
- Sound samples: Kenney RPG Audio / Impact Sounds selections, CC0 1.0 Universal. Source OGG files are retained in `source_sfx/`; runtime effects mix licensed source recordings with the project's original synthesized layers. These are not represented as a custom human-recorded Foley session.
- Kingdom score: original procedurally composed 36-second stereo score from `tools/asset_pipeline/generate_audio.py`. The TAD CC0 track is retained as an optional reference only and is not the runtime theme; this is not a commissioned orchestral recording.
